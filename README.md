# BRAIN BBQS Knowledge Graph

Interactive force-directed visualization of the BRAIN Behavior Quantification and Synchronization consortium — working groups, projects, people, products, events, and announcements.

**To add or update data:** edit `bbqs.ttl` (the inline TTL block in `index.html`) and push. The graph re-renders automatically.

Live site: https://brain-bbqs.github.io/knowledge-graph/
